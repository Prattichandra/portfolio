03 — CASE STUDIES

Five projects, five different rooms full of stakeholders.

01/052015–16
Tech Mahindra

Network Fleet Console

Verizon · B2B · Telecom & network operations

Context

Network operations and field technicians needed one console to monitor and manage a geographically spread fleet of network devices, instead of piecing status together across tools.

Process

Heuristic evaluation of the existing console first, then low-to-high fidelity wireframes and an interactive prototype, validated with operations stakeholders on navigation and alerting.

Outcome

A responsive console design spanning desktop and field-mobile use, handed off with a documented UI component library for the build team.

02/05Tech Mahindra
Heuristic audit

Lube Chart Selector

Chevron · B2B · Oil & gas, field service

Context

Field technicians needed a fast, reliable way to find the correct lubricant grade for a piece of equipment, in place of a dense manual reference chart.

Process

Ran a heuristic analysis of the legacy chart, then designed a structured, filterable lookup tool built around scanability under field conditions.

Outcome

A task-oriented selection flow that replaced a static chart, taken from wireframe through to high-fidelity design as part of Chevron's usability review.

03/052018–22
Conduent

WSS Admin & Borrower Portal

Loan Manager suite · B2B · Banking & mortgage servicing

Context

Loan servicing staff and borrowers worked across separate, disjointed tools — Admin Portal, CSR Portal and Web Self Service — to manage the same loan accounts.

Process

UX single point of contact across the suite: user flows and wireframes for the Admin and Borrower-facing WSS experience, plus a shared component library for consistency.

Outcome

A consistent, accessibility-reviewed design language spanning CSR, Admin and Borrower touchpoints, replacing three inconsistent tools with one.

04/05Tech Mahindra
Patient-facing

Video Consultation Experience

Healthcare provider · B2C · Telehealth

Context

Patients needed a straightforward way to book and join a video consultation with a provider, without the process feeling like a barrier to care.

Process

Designed the full flow — scheduling, waiting room, in-call controls, post-visit summary — through wireframes and an interactive prototype, then usability-tested it against less tech-confident patients.

Outcome

A booking-to-follow-up flow designed so the technology stays out of the way of the actual consultation.

05/05Tech Mahindra
Self-service

Return Policy Flow

Cisco · B2C · Enterprise retail & support

Context

Customers needed a clear, self-service way to understand return eligibility and start a return, rather than reading policy copy or calling support.

Process

Mapped the existing return journey, flagged friction points through a heuristic review, and redesigned it as a guided, step-based flow.

Outcome

A self-service return flow delivered as browser-compatible mockups, cutting the journey down to the decisions that actually mattered.
